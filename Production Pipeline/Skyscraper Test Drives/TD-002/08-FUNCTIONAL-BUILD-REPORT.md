  information-extraction authority. The protected reference journey and
  normal controller now invoke the same evaluator truth.

- `CalibrationMarginExtractionCheckpoint.js` owns one separate sanitized
  extraction prefix under
  `horizon-archive-rp003-extraction-checkpoint-v1`.
- Exact keys, IDs, forms, all-true dimensions, bounded metadata, order, null
  deltas, unchanged continuation, and null successor are mandatory.
- P0 contains no IE evidence; P1 contains primary; P2 contains primary plus
  retrieval; P3 contains primary, retrieval, transfer, and unsupported
  explanation.

- A rejected, false, throwing, malformed, partial, duplicate, out-of-order,
  private, cross-credit, save, route, or later-state candidate leaves the
  prior exact prefix byte-for-byte stable.

### Controller and normal-route composition

- `CalibrationMarginExtractionFloor.js` owns exact entry validation, seven
  modalities, one-hit tokens, group replacement, blank forms, strict scoring,
  answer-free repair, clear, retry, interlude, resume, return, atomic commit,
  recovery, and finalization.
- Validation precedes token consumption. Incomplete native/client validation
  does not call the evaluator, increment an attempt, or write evidence.
- Every evaluated miss clears all selections, explanation, confidence,
  evaluator inputs/results, and transient token history before mounting only
  the actual failed dimension IDs and/or explanation boundary.
- Every retry is a newly keyed, genuinely blank form.
- CM-32 creates no durable marker and grants no evidence. Reload at P1
  reconstructs CM-32; its explicit continue mounts a fresh blank retrieval.
- P0 and P1 authorized returns are write-free, private-cleared, and require a
  new entry action. There is no late-chain return.
- `CalibrationMarginNormalEntry.js` decorates exact accepted Python P3 with
  one fresh extraction action, preserves Python and observation evidence
  byte-for-byte, and composes exact IE resume without importing the protected
  complete journey.
- `App.jsx` uses the separate sanitizer and key. No learner answer, prose,
  evaluator object, token, focus history, or active/failed work enters either
  checkpoint.
