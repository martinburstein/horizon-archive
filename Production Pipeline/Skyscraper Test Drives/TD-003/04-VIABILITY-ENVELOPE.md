## Five-conjunct firewall

The checklist is one Boolean conjunction, never a score:

| Order | Conjunct | Exact proof | Cannot be supplied by |

| 1 | Observations | exact set `correspondence`, `bounded_difference`, `sealed_unavailable` | either learning chain, presentation, review, or save |
| 2 | Python | exact ordered finalized `PY-010` primary, retrieval, transfer records | observations, IE, confidence, Tour, or restore |
| 3 | Information extraction | exact ordered finalized `RP003-IE-01` primary, retrieval, transfer, unsupported-explanation records | observations, Python, provenance copy, or save |
| 4 | Provenance | every retained value traces only to exposed/supplied input; unavailable remains unavailable | completion, null display, world imagery, or confidence |
| 5 | No external action | unchanged `continuation`; null city/world/access effects; null successor; no authority/external action | any other completed conjunct |

Evaluation order is fixed 1 through 5. A failure names the first invalid
underlying boundary. No later conjunct can compensate for an earlier one.

it creates no evidence record, score, mastery, observation, save eligibility,
route, or world state.
