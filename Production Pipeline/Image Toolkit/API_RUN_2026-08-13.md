# Private API Image Run — 2026-08-13

## Authority

- Authorized budget: 10 attempts total.
- Attempts 1–2 were mistakenly made with the built-in generator and count
  honestly against the same budget.
- Attempts 3–10 used the bundled Image API CLI with `gpt-image-2`, high quality,
  opaque PNG, one sequential request at a time.
- API sources were generated at 1920×1088 and normalized privately to exact
  1920×1080 RGB PNG.
- No API candidate was displayed in chat.

## Result

- Ten of ten attempts consumed; eight were API generation/edit requests.
- All returned API candidates passed the exact Full HD technical gate.
- No candidate passed the complete semantic acceptance rubric.
- The strongest families established a valid low concavity, basin context, and
  three-material palette, but retained at least one hard failure in physical
  interlock, cross-material wear, recessed void depth, or anti-biological /
  anti-human readability.
- No image was imported or integrated. The null-first product fallback remains
  unchanged.

## Reusable lesson

Start future work from the hard-surface composite direction, but treat visible
material depth, pairwise interlock, differentiated wear response, and angular
under-surface voids as independent acceptance gates. Do not spend more than two
edits on a family that drifts toward roots, grids, platforms, or cracked ground.
