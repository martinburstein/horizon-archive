# Image prompt template

Keep the completed prompt compact. Delete lines that do not help.

```text
Use case: stylized-concept
Asset type: game environment plate
Primary request: <one-sentence subject and purpose>
Scene/backdrop: <place and essential context>
Subject: <main focal relationship>
Style/medium: cinematic environmental concept art; grounded material realism
Composition/framing: <camera, scale, focal placement, crop needs>
Lighting/mood: <light and emotional register>
Materials/textures: <only details essential to this asset>
Must show: <short semicolon-separated list>
Constraints: no text; no watermark; preserve <critical invariants>
Avoid: <short list of likely failure modes>
```

For a targeted edit, use:

```text
Change only: <one visual issue>.
Keep unchanged: <composition, camera, subjects, passing relationships, style>.
Constraints: no extra elements; no text; no watermark.
```
