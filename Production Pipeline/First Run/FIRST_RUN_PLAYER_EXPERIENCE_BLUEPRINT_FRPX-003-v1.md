closes onto the unchanged basin. Focus moves once to a newly legible semantic
region over six unequal relations crossing two dry foreground lips. The Pilot
notices the repetition first; one Suit/System confirmation identifies a

`L02-02` work. A miss, safe close, Escape, reload, Meadow round trip, primary
acknowledgement, transfer, explanation, mastery, and completed revisit leave
the water, branches, Crown, route, and world unchanged.

  disconnected trigger and uses Host 04 or the earliest safe enabled Drowned
  fallback exactly once.
- Malformed or noncontiguous Host 04/evidence state cannot expose Host 05,
  generic `L02-02`, later continuation, replay, or credit. Recovery never
  deletes, repairs, promotes, or rewrites durable state from this view layer.
