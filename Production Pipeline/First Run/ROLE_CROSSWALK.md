## Design rule

First Run changes each role's production purpose, not its professional talent.
Stable IDs, file identities, discipline boundaries, independence rules, and
sequential handoff order are retained. The unit of work changes from building a
new playable slice to closing one evidenced quality gap in the existing full
first playthrough.

| Role | Preserved talent | First Run purpose |
| --- | --- | --- |
| Commandant | audience, product promise, scope, quality, priority | Define the observable full-game finish line and rank player value |
| Colonel | world, narrative, canon, mystery, tone, continuity | Reconcile game-on-paper and runtime; lock what polish must communicate without new lore |
| Operations Planning Major | sequencing, dependencies, pacing, routes, bounded scope | Maintain the full-game maturity map and select the earliest justified Work Order |
| Office of Science Administrator | systems, learning evidence, privacy, accessibility, save, performance, QA | Make visible polish technically and educationally safe and independently testable |
| Mission Captain | cross-discipline integration and versioned contracts | Issue one conflict-free First Run Shell with exact quality and rollback gates |
| Reconnaissance Sergeant | emotional direction, fantasy, mood, rhythm, sensory identity | Give the selected gap a directorial interpretation that improves the felt journey |
| Tactical Operations Specialist | state/interaction/focus/responsive/recovery design | Specify exact polished player flow across all required modalities and layouts |
| Combat Engineer | production code, state, persistence, tests, builds | Implement the vertical-quality pass robustly in the real game |
| Quartermaster | copy, learning presentation, content completeness, asset stewardship | Retire content placeholders and supply approved final-purpose material |
| Image Specialist | lighting, color, sound, motion, composition, hierarchy, visual accessibility | Finish runtime presentation using unchanged accepted media and code/configuration treatment |
| Intelligence Officer | independent release audit, variance classification, reconciliation, sync | Prove the candidate, advance only evidenced maturity, and choose the next exact edge |

## Deliberate boundary adaptation

The Skyscraper Image Specialist profile included image generation and a cycle
reveal. Martin disabled that component before First Run. The successor keeps
the role's atmosphere and presentation talent but removes generation, editing,
replacement, variation, import, and reveal duties. This is a scope boundary,
not a removal of the role's core craft.

## What no role may reinterpret as polish

- new story, branch, packet, lesson, reward, access, or ending;
- hidden-lore access or a Machine/Builder answer;
- world response to pass/fail;
- relaxed learning evidence, privacy, save, accessibility, or offline rules;
- visual spectacle that communicates unsupported correctness or authority;
- a maturity advancement based only on plans, screenshots, or specialist claims;
  or
- recurring automation without Martin's explicit authorization.
