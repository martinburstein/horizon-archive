## Frozen built-in managed-ingress protocol

This protocol is mandatory and replaces the literal v1 first-byte OS-temp
requirement. Science must revalidate it before Mission freezes its executable
details. Quartermaster alone may later perform it after the Combat manifest
gate passes.

1. **Built-in only.** Each attempt is exactly one sequential call to the
   shell-approved built-in image-generation tool, with no referenced or
   conversation image input and no edit/variation mode. CLI, REST/API, browser,
   extension, alternate generator, and manual-file fallback are forbidden.
2. **One direct return.** The call must return exactly one unique local absolute
   pathname directly for exactly one managed output. The path must be beneath
   the shell-frozen tool-owned managed `generated_images` root and outside the
   resolved Horizon repository and every protected/user/browser/save/residual
   root. These are scalar containment checks on the returned path; listing,
   globbing, searching, or enumerating the managed parent is forbidden.
3. **Opaque stop conditions.** An unknown, absent, nonlocal, nonunique,
   multiple, ambiguous, unowned, or in-repository return; an unavailable exact
   managed root; or any containment uncertainty consumes the ordinal and stops
   the whole cycle opaque. It does not authorize discovery, parent listing,
   another attempt, fallback, inspection, import, reveal, or cleanup of any
   path other than an exact proven returned file.
4. **Fresh evaluation child.** Before the call, create one fresh GUID-named
   child of the resolved OS temporary directory through a shell-frozen exact
   path, prove that child outside the repository and protected roots without
   listing its parent, and predeclare only `attempt-0N.png` within it.
5. **Identity copy.** Copy only the exact returned managed file to the exact
   predeclared temporary candidate path. Before any rubric or pixel check,
   record exact byte length and SHA-256 for both files and require equality.
   Identity mismatch consumes the ordinal and stops the cycle opaque.
6. **Immediate managed cleanup.** Immediately after identity proof and before
   any candidate rubric inspection, delete only the exact returned managed
   pathname. Prove that exact file absent. Missing-before-cleanup state,
   deletion failure, uncertain ownership, or unverifiable absence stops the
   whole cycle opaque. It does not authorize listing, recursive/pattern
   cleanup, retry, reveal, import, or another attempt.
7. **Temporary evaluation only.** After managed cleanup succeeds,
   Quartermaster may inspect the exact temporary candidate against PNG/color/
   dimensions/bytes/metadata/decode and every physical/composition/source/
   six-layout/access predicate. Any failure consumes the ordinal and rejects
   the candidate.
8. **Rejected cleanup.** A rejected candidate never enters the Horizon
   workspace, source control, runtime, preview, browser, report, Markdown,
   cycle reveal, publication, sharing, or another host. Freeze only its ordinal,
   prompt version, tool identity if supplied, pass/fail rubric facts, and

   prove it absent. Rejected candidate bytes, SHA, pathname, and pixels are not

9. **Passing selection.** At most one passing candidate may be selected. Copy
