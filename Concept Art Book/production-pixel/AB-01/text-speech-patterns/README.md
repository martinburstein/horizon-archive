# Text/Speech Patterns Motif

[![Six linked text and speech stations](text-speech-64x64.png)](text-speech-64x64.png)

Native `64 x 64` AB-01 overlay: text capability, directional recognition/synthesis, multimodal spoken prompt, client configuration, result/error/cancellation, and disclosure/action safety. Cancellation is a two-capped reversible broken loop. Disclosure and action use separate external locked exits. Shape, value, pattern, and continuity carry meaning; color never acts alone and no text is embedded.

QA: [exact 2x](qa/2x.png), [grayscale](qa/gray.png), [six-station isolation](qa/isolation-2x.png), [renderer](build.py). Use anchor `x=156,y=211`, hotspot `68 x 76`; no interface/footer intrusion. Live labels and transcripts are mandatory, including direction, error, cancellation, disclosure, and authorization state.
