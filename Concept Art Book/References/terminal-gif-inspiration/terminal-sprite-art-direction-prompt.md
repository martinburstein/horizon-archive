## Implementation timing

Recommended six-frame loop durations in milliseconds: `520, 180, 240, 220, 140, 420`. Insert an additional `700-1100 ms` dark hold at irregular intervals in runtime if the engine supports it. The membrane may brighten the adjacent collar by one logical pixel; no other geometry should pulse.

## Production reduction gate

Generated output is exploration only. Before integration, rebuild or deliberately reduce each selected cell to `64 x 64`, verify identical body pixels across all frames, restore hard alpha edges, use nearest-neighbor presentation, and reject any frame that changes silhouette, camera, debris, or object pose.
