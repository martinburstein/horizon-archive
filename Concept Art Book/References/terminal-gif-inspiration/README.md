# Terminal GIF Inspiration Reference

This package makes Martin's 10.67-second 4K gameplay capture inspectable without treating the referenced object as a design to copy. The capture is an external visual reference from *No Man's Sky*. Its durable Horizon Archive value is the contradiction it creates: a world classifier calls the object a mineral, while an embedded warning surface continues broadcasting to an audience that may no longer exist.

## Extraction coverage

- Source: `Terminal GIF Inspiration.mov` in the repository root, retained locally and excluded from Git because it is large and contains unrelated device metadata.
- Video: `3840 x 2160`, `30 fps`, `320` frames, `10.6667` seconds.
- Every decoded video frame: `extracted/frames/full-resolution/frame_0001.jpg` through `frame_0320.jpg`.
- Complete local index: `extracted/contact-sheets/all-frames-20x16.jpg`.
- Readable local sequence sheets: ten files under `extracted/contact-sheets/`, each containing 32 consecutive frames.
- Frame/time lookup: [frame-manifest.csv](extracted/metadata/frame-manifest.csv).
- Sanitized technical metadata: [video-metadata.json](extracted/metadata/video-metadata.json).
- Audio: a local mono 16 kHz extraction is retained outside Git; no speech transcript is claimed.
- OCR: no human-readable source text is claimed. The screen marks are analyzed as changing graphic states, not translated language.

The source MOV, decoded frames, audio, and contact sheets remain local and are excluded from Git. This avoids redistributing the external gameplay footage or its unrelated container metadata while retaining the original sprite prompt, sanitized manifest, and Horizon Archive derivative assets in project history.

## Frame-grounded visual analysis

The object's interest comes from five simultaneous reads:

1. **Mineral at first glance.** The pale shell is continuous, weathered, partly swallowed by ground cover, and capped by green-black mineral or biological accretion. It has no visible stand, door, keyboard, or conventional chassis.
2. **Manufacture on second glance.** A precise vertical seam interrupts the shell. A dark inset collar holds the display. Those relationships are too deliberate to read as random geology, yet they do not reveal an obvious human assembly method.
3. **A signal that never resolves.** The display cycles through black, a red ember, a bright red field, a pale ring, four block-like marks, washed static, and diagonal interference. It resembles a warning, handshake, or diagnostic loop without confirming which.
4. **Survival through repetition.** The sequence repeats while the surrounding object stays inert. The tiny persistence is more unsettling and sympathetic than a dramatic activation: it is still doing one job long after its context disappeared.
5. **Environmental abandonment.** Vegetation occludes the base instead of framing it like a shrine. The object appears discarded, stranded, grown over, or simply left in service—not staged for the player.

## Horizon Archive translation

Preserve the contradiction, not the source silhouette. A Builder Terminal inspired by this reference must:

- be unmistakably **non-oval** and original: an asymmetric cleaved wedge or stepped mineral block, half-buried and grown into the site;
- make its surface strata continue through the housing so a human could initially misclassify it as geology;
- embed one small off-center rectangular warning membrane with clipped corners, never a round lens copied from the reference;
- omit controls, labels, keyboard, stand, human-facing screen angle, ergonomic height, or bilateral console symmetry;
- show repair seams, mineral accretion, silt/vegetation occlusion, and at least one older sealed interface scar;
- animate only the membrane and a tightly localized physically plausible routed light spill: dark hold -> seed node -> spectral scan -> abstract topology -> displaced phase contours -> interference -> dark hold;
- keep the abstract marks nonlinguistic and nondecodable. Their timing communicates persistence; their content does not reveal canon;
- feel quiet and functional, not haunted, magical, cute, or aggressively threatening;
- use one high-resolution photorealistic master body/camera plate; build the loop by changing only a masked membrane/emission layer so body and environment remain exactly registered.
