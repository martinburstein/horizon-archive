# City Threshold Production Plates

Generated on 2026-07-15 as the first production replacement for the historical `Underground City.png` staging raster.

## Runtime package

- `city-threshold-overview-640x360.png` and `city-threshold-overview-320x180.png`
- `city-threshold-boundary-640x360.png` and `city-threshold-boundary-320x180.png`
- `city-threshold-access-640x360.png` and `city-threshold-access-320x180.png`
- `*-source.png` files preserve the image-generation masters for future authored pixel cleanup.

The runtime selects the native or narrow file from the canonical frame layout. Presentation remains nearest-neighbor/pixelated. The detail plates are distinct views of the same place rather than color filters over the overview.

## Provenance

The overview was generated from an original Horizon Archive brief with the built-in image generator. It does not use or reproduce an external game frame or prior concept plate. The boundary and access plates use only the generated overview as a visual-consistency reference.

The 640×360 and 320×180 files were normalized mechanically from their matching masters with nearest-neighbor sampling. They are candidates for live aesthetic review; the source masters remain available for a future hand-authored cluster pass. Animated heat/vapor effects remain separate runtime layers.
