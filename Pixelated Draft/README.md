# Pixelated Draft — Retired Visual Direction

Status: **ARCHIVED / NOT ACTIVE**

This folder preserves Horizon Archive's earlier pixel-art direction, specifications, specialist reviews, production experiments, and implementation contracts. It remains available as historical design evidence, but it must not govern new art, current scene drafts, agent reviews, or release decisions after 2026-07-15.

The active visual authority is `Visual Direction/PHOTOREALISTIC_CHARTER.md`.

One distinction remains active: the gameplay structure may continue to draw broad inspiration from classic LucasArts point-and-click adventures. That means scene-based exploration, readable interactions, recoverable experimentation, expressive locations, and compact interface storytelling. It does **not** mean adopting their rendering technology, pixel density, resolution, palette, or period graphics.

## Archived contents

- `RETIRED_PIXEL_DIRECTION.md` — consolidated record of Martin's former pixel requirements.
- `Pixel Patrol/` — retired pixel specialist specifications and work logs.
- `Curse Art Director/` — retired art-direction studies tied to the earlier illustrated/pixel target.
- `pixel-production-contract.md` — retired game rendering contract.
- `production-pixel/` — retired pixel-production assets and documentation. Some assets may remain temporarily referenced by the playable demo until replaced; that is migration debt, not active visual approval.
- `Instruction Snapshots/` — pre-migration copies of active instructions and drafts that contained pixel requirements.

Historical work logs outside this folder may continue to mention pixel rules because they record work that actually occurred. Those mentions are not active instructions.
