# Pixel Patrol

Pixel Patrol defines the production rendering system for Horizon Archive. The target is an original 640 x 480 square-pixel adventure that feels at home beside late-SCUMM Windows games without copying their protected art, writing, characters, layouts, icons, fonts, or assets.

The concept-art book supplies mood, landmarks, scale, and route intent. It is not a source of production pixels. Every shipped scene is rebuilt deliberately on the logical grid.

## Evidence labels

- **Observed fact:** explicitly documented by a primary or technical source.
- **Measured estimate:** counted or bounded from displayed media; allow the stated tolerance.
- **Design inference:** a repeatable visual conclusion supported by multiple examples.
- **Horizon adaptation:** an original rule chosen for this game, including its persistent dialogue band and learning Terminals.

## Copyright-safe boundary

This folder contains only written analysis and an original geometric benchmark. It contains no frames, screenshots, video, audio, sprites, fonts, dialogue, names, jokes, scene layouts, icons, or extracted data from The Curse of Monkey Island.
