# Return Is Navigation, Not a Score

After you have earned the completed Glass Meadow route, Chapter II can show the visible action **`Return: Glass Meadow`**. Its accessible name is **`Return to Chapter I, Glass Meadow`**.

Using that action restores the completed Glass Meadow scene and puts focus on the already-earned forward choice. It does not run Python, submit an answer, or create assessment evidence.

## Read the four state layers separately

| State layer | What a return can restore | What a return never creates |
| --- | --- | --- |
| Navigation | Your previously unlocked scene and the action needed to continue | A new route unlock, story reward, or exercise completion |
| Scene display | The completed/crowned route marker and the route-open summary already earned | A fresh Machine response or a second completion event |
| Working session | No open Terminal workspace travels with you; each exercise's session notice controls what reopens | Recovered source, traceback, output, or notes that the session contract says were cleared |
| Mastery evidence | Existing privacy-limited evidence remains separate from navigation | A new attempt, point, pass, mastery status, objective completion, exam-progress credit, or readiness decision |

Restoration means **show the last valid state again**. It does not mean **score the state again**.

## Returning and leaving again

1. In Chapter II, choose **`Return: Glass Meadow`**.
2. Review the restored scene if you wish. Merely looking at a marker, route summary, or completed scene changes no learning evidence.
3. To revisit Chapter II, choose **`Depart: Drowned Archive`**. Its accessible name is **`Depart for Chapter II, The Drowned Archive`**.
4. If Chapter II was already completed, its retained scene state or next available action may reappear. That is still restoration, not a fresh assessment result.

Only an explicit exercise action described by that exercise—such as running a form, submitting retrieval answers, or satisfying its stated gate—can produce new learning evidence. The existing calibration gate remains **8/8 + 8/8 + 4/4**, with both diagnoses recorded before editing and no unresolved critical misconception. Returning to a scene cannot weaken, satisfy, or bypass that gate.

## Privacy, authority, and readiness boundary

- Saved mastery evidence may retain bounded IDs, check results, counts, confidence, misconception tags, and mastery status.
- It does not retain learner source code, traceback text, runtime-output text, or free-form notes.
- This navigation action does not call Microsoft Foundry or Azure, use credentials, authorize service changes, or grant authority for any external action.
- A restored scene is not AI-901 exam progress. Exam readiness comes only from the curriculum's explicit assessment and readiness gates.
- This course-authored guidance is not a Microsoft exam question and does not guarantee an exam result.

## Quick retrieval check

1. You return to the completed Meadow and see its crowned marker. Did you earn a new pass? **No. The scene display was restored.**
2. You choose `Depart: Drowned Archive` after returning. Does departure add exam-progress credit? **No. It changes navigation only.**
3. Can a restored route summary replace the calibration's 8/8 + 8/8 + 4/4 gate? **No. Only the stated assessment evidence can satisfy that gate.**
4. Should cleared source or traceback text be reconstructed from a scene return? **No. Working data follows its exercise session contract and stays separate from saved mastery evidence.**
