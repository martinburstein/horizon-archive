# Optional Calibration or Depart

The required route is already complete. You now have two valid choices:

- **Optional calibration:** practice reading and repairing two small Python errors.
- **Depart:** continue to the next survey site without starting calibration.

Calibration never opens, closes, or changes the route. A wrong answer changes only the calibration feedback.

## If you choose calibration

Use one repeatable debugging loop:

```text
locate → classify → repair one thing → rerun
```

You will:

1. read a `NameError`, record its error type, line, and misspelled name, then repair the name;
2. read a fresh `IndentationError`, record its location, then indent the instruction that belongs inside the block;
3. answer four closed-note retrieval questions.

Optional does not mean unscored. Calibration mastery still requires both diagnoses before editing, **8/8 on each form**, **4/4 retrieval**, and no unresolved critical misconception. Keyboard operation and speed are never scored.

## Save, exit, and departure boundaries

- **Exit and reopen in the same scene:** restore the current calibration source, diagnosis, results, and hint level.
- **Reload or resume:** start with a clean working form while keeping privacy-limited mastery evidence.
- **Depart to the next scene:** clear working source, traceback, output, and scratch state. Completed mastery evidence remains separate.
- **Mastery evidence:** may include lesson/activity/exercise IDs, diagnosis/check booleans, attempt and hint counts, confidence, misconception tags, and mastery status. It excludes source code, traceback/output text, and free-form notes.

## Quick choice check

1. Must you complete calibration before departing? **No**.
2. Does a failed run close the route? **No**.
3. If you start calibration, does its mastery gate become optional? **No—the practice is optional, but its gate remains strict**.
4. What clears when you depart? **The temporary working session, not saved mastery evidence**.
