# L-06-03 — Capstone and exam readiness checkpoint

## Outcome and source boundary

Design and defend one offline capstone that integrates a Foundry client flow (`AI901-D2-O3`), text/speech patterns (`AI901-D2-O5`), and Content Understanding extraction (`AI901-D2-O7`). The current [AI-901 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ai-901) controls scope; implementation details route through the [official source register](../../sources/current-official-source-register.md).

No source content, audio, credential, endpoint, or service is used. These course-authored scenarios are not Microsoft exam questions and cannot guarantee an exam result.

## Guided offline capstone

Design a communication-archive pipeline without running it:

1. Trace endpoint, approved identity boundary, deployment/capability, request, response, and error handling.
2. Select text analysis for existing written feedback; recognition for audio-to-text; synthesis only for text-to-audio.
3. Define a Content Understanding schema. Preserve unsupported values as null and retain available evidence/provenance.
4. Specify validation, per-item failure, cancellation, privacy, and session-clear behavior.
5. Label every simulated output and prohibit live calls or external consequences.
6. Explain the design closed-note using current official terms.

## Readiness decision

The capstone assessment is necessary but insufficient. `ready_for_next_practice_checkpoint` requires 12/12 on both forms, all 15 `L-06-01` objectives ready, every `L-06-02` remediation route closed with fresh evidence, and a closed-note explanation. Otherwise use `remediate_before_checkpoint` or `insufficient_evidence`.

## Privacy, accessibility, session, volatility, and safeguards

Store scores, artifact checks, objective IDs, and readiness state—not content, audio, transcripts, credentials, endpoints, payloads/responses, exam item text, or external-action requests. Clear working content/configuration/scenario state on scene transition; persist mastery separately. Controls use labels, keyboard order, text status, associated feedback, media text equivalents, a live region, no timer, and reduced motion.

Exam scope and Foundry portal, SDK/API, analyzer, model, capability, region, price, preview, and deprecation details are volatile and must be reverified.

No capstone result, score, confidence, prompt, or simulation guarantees an exam result or authorizes service calls, credential use, Azure mutation, email, disclosure, publication, purchase, or deletion. External/destructive action requires separate verified scope, privacy review where applicable, authority, and confirmation.
