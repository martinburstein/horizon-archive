# Before Your First Terminal

This is course-authored Python practice, not a Microsoft exam question. You are not expected to know Python yet, and completing this orientation does not guarantee an AI-901 result.

## Four quick steps

### 1. Run one real Python file

```python
message = "Terminal found."
signal = 1
print(message)
print("Python signal:", signal)
```

The first two lines save values in variables. The last two display output. Select **Run** to execute the file.

### 2. Inspect, hint, and retry

If Python reports an error, the lesson is not lost. Inspect the named line, use a hint if needed, edit the file, and select **Run** again. A code mistake cannot damage the world or consume the lesson.

### 3. Keep three kinds of information separate

- **Local save:** Slot 01 and the display name stay in the browser-local expedition save. The name labels the Pilot's recorder; it is not Python code, a credential, Machine memory, or mastery evidence.
- **Working session:** current code, hint position, and output are temporary. Closing and reopening this Terminal can restore the current session; reload, resume, completion, or scene transition clears it.
- **Mastery evidence:** the course stores only allowlisted identifiers and bounded check data such as attempts, hint use, and completion—not the display name, source code, output, credentials, or private notes.

### 4. Predict one changed output

After changing `signal = 1` to `signal = 2`, saving, and selecting **Run**, the second output line should be:

```text
Python signal: 2
```

## Quick check

1. Which control runs the file? **Run**.
2. Does an error end the lesson? **No—inspect, hint, and retry**.
3. Does the display name become Python code or mastery evidence? **No**.
4. What follows a saved change to `signal = 2`? **The second line shows `Python signal: 2`**.
