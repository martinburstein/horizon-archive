# Before Your First Terminal

You have found a Terminal. Nothing expects you to know Python yet.

## What you will do

1. Open the Terminal and read one short task.
2. Look at a small Python file and predict what it will display.
3. Select **Run**. The Terminal shows the program's output or a readable error.
4. Change one value, save the file, and run it again.
5. If something fails, inspect the named line, use a hint if needed, and retry. You cannot damage the world or lose the lesson by making a code mistake.

This is real Python syntax:

```python
message = "Terminal found."
signal = 1
print(message)
print("Python signal:", signal)
```

The first two lines save values in variables. The last two lines display output. Changing `signal = 1` to `signal = 2` changes the second output line after you save and run again.

## Three kinds of saved information

- **Local character/save data:** Slot 01 and the display name chosen during the opening stay in the browser-local expedition save. The name labels the Pilot's recorder. It is not sent into your Python file, is not a credential, and is not remembered by the Machine.
- **Terminal working session:** your current code, hint position, and most recent output are temporary working state. Leaving the current session may clear that draft; the interface must warn before discarding unsaved work.
- **Mastery evidence:** the curriculum may separately record the lesson/activity ID, whether a check passed, attempt and hint counts, confidence, and a review flag. It does not need your character name, Python source, output text, credentials, or private notes.
