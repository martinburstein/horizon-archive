# CUM-01 — AI-901 cumulative confusion-pairs checkpoint

## Why this exists

All mapped lessons are packaged. This checkpoint tests whether distinctions survive across lesson boundaries, using the current [AI-901 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ai-901) and the [official source register](../../sources/current-official-source-register.md). Each form has eight mixed scenarios whose objective tags collectively cover all 15 objectives.

## Guided warm-up

Explain these pairs without notes: responsible practice vs technical capability; model vs deployment; analysis vs generation; speech direction vs extraction; prompt vs agent; portal evidence vs client evidence; workload-specific service patterns; valid output vs permission to act.

For each pair, give one decision rule and one failure example. Do not memorize scenario wording.

## Gate and remediation

Complete primary using [check.md](check.md). A correct label with a wrong reason is still a miss. Route all objectives tagged on a missed item through `remediation_routes.json`, retrieve the distinction, repair one guided case, then take fresh transfer. Advance only at 16/16 on both forms with all 15 objectives covered. Repeat retrieval tomorrow, in three days, and in seven days after reverifying the study guide.

## Safeguards

Store only checkpoint/item IDs, objective tags, dimension correctness, attempts, hints, confidence, misconception tags, and mastery—not exam item text, private notes, credentials, endpoints, payloads, responses, source content, or action requests. Clear working answers/runtime state on scene transition; persist mastery separately.

Controls have persistent labels, keyboard order, text status, associated feedback, text equivalents, a live region, no required timer, optional time recording only, and reduced motion. Exam scope and Foundry portal/SDK/API/model/tool/pricing/preview details are volatile and must be reverified.

These are course-authored scenarios, not Microsoft exam questions. Passing cannot guarantee an exam result and does not authorize service calls, credential use, Azure changes, email, disclosure, publication, purchase, or deletion. External/destructive action requires separate verified scope, authority, privacy review where applicable, and confirmation.
